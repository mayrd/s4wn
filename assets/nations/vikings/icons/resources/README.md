# Resource Icons — Vikings

## Purpose
Small UI icons for **resource** types in HUD, economy overlay, and logistics UI.

## What is expected here
Sub-files: `icon_{resource}.png` for each of the 19 ResourceType values (wood, stone, iron, coal, gold, sulfur, food, planks, tools, weapons, beer, etc.).

## How assets are consumed
Referenced by `resourceIcon()` in economy / Object Explorer code.
