# Building Textures — Trojans

## Purpose
Diffuse / material texture maps for **buildings**.

## What is expected here
Sub-files: `building_{material}.png` (e.g. `building_timber.png`, `building_stone.png`, `building_marble.png`, `building_thatch.png`) or building-specific textures. 1024x1024+ PNG, SRGB.

## How assets are consumed
Referenced from `nation.json -> buildings[].texture`.
