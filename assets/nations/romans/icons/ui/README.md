Nation-specific UI assets: emblem, loading background, and theme-specific UI elements.

## What is expected here
Sub-files: `emblem.png`, `loading_bg.png`, and any nation-themed UI button / panel textures. Generated from Gemini using prompts in `nation.json -> assetGeneration.geminiPrompts`.

## How assets are consumed
Referenced from `nation.json -> visuals.emblem` and `visuals.loadingBg`.
