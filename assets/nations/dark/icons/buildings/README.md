# Building Icons — Dark Tribe

## Purpose
Small UI icons (typically 64x64 RGBA PNG) for the **build menu**.

## What is expected here
Sub-files: `{buildingKey}.png` — one per building kind (e.g. `castle.png`, `sawmill.png`, `storage_yard.png`).

## How assets are consumed
Referenced from `nation.json -> buildings[].icon`.
