# Unit Icons — Dark Tribe

## Purpose
Small UI icons (64x64 RGBA PNG) for **units** in the HUD, training menu, and unit inspection panels.

## What is expected here
Sub-files: `{unitKey}.png` or `unit_{unitKey}.png` (e.g. `worker.png`, `soldier.png`, `archer.png`, `settler.png`, `medic.png`).

## How assets are consumed
Referenced from `nation.json -> units.{unit}.icon`.
