# Terrain Textures

## Purpose
This folder contains **terrain-type texture atlases** — one large PNG per terrain
type. The `TerrainRenderer` (`src/rendering/TerrainRenderer.ts`) loads these as
the base diffuse textures for the splat-mapped ground mesh. Each texture is a
single opaque (or RGB) PNG that tiles across its terrain regions.

## What is expected here
All files follow the `terrain_{type}.png` naming convention. Each is a
square texture (1024×1024 or 2048×2048) with rich, S4-authentic patterns.

| File | Terrain type | Approx. size | Description |
|------|-------------|-------------|-------------|
| `terrain_grass.png` | Grass | 1516 KB | Fertile grassland with wildflower speckles — buildable |
| `terrain_forest.png` | Forest | 1106 KB | Darker grass with tree coverage |
| `terrain_desert.png` | Desert | 1147 KB | Sandy dunes with pebble details |
| `terrain_mountain.png` | Mountain | 1267 KB | Stratified rock layers, unbuildable |
| `terrain_snow.png` | Snow | 737 KB | Snow drift patterns, ice sparkles |
| `terrain_water.png` | Water | 1142 KB | Gentle ripples, shallow water |
| `terrain_swamp.png` | Swamp | 947 KB | Algae patches, lily pads, twisted roots |

## Naming convention
`terrain_{type}.png` where `{type}` is one of: `grass`, `forest`, `desert`,
`mountain`, `snow`, `water`, `swamp`, `deepwater`.

## Regeneration
Terrain textures are procedurally generated by:
```bash
python3 scripts/generate_terrain_textures.py
```
See `scripts/generate_terrain_textures.js` and `assets/MODEL_LISTING.md` for
the Gemini prompts and noise parameters used to create the S4-authentic patterns.

## Format notes
- **PNG**, 8-bit or 16-bit RGB(A).
- No alpha channel is required (terrain tiles are opaque), but alpha is
  tolerated for blending.
- Textures should tile seamlessly.

## Asset Policy
These are **procedurally generated** textures, not extracted from the original
Siedler 4 game. See `AGENTS.md` Asset Policy.
